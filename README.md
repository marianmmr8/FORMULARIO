# Formulario de inicio de sesión

Este proyecto es una página web sencilla que muestra un formulario para iniciar sesión.

## Campos

- Nombre
- Correo electrónico
- Contraseña

Los campos son obligatorios y el formulario incluye un botón para enviarlos.

## Tecnologías

- HTML
- CSS

## Estilo

El título del formulario está centrado con la propiedad CSS `text-align: center;`.
